# Разбор смены линии маркировки

Небольшой сторож для поиска расхождений между фактическим движением туб и
записями станции упаковки.

## Задача

По журналам станции, ПЛК, маркиратора и коробов нужно восстановить ход смены и
найти четыре вида проблем:

- код записан в короб, но соответствующей тубы в нём нет;
- в короб попала лишняя или нечитаемая туба;
- один код нанесён на две тубы;
- один код записан в два короба.

Сторож должен работать и на других сменах той же линии, где могут отличаться
скорость ленты и размер короба. Поэтому в коде нет фиксированных номеров туб,
кодов, SSCC, скорости или количества туб в коробе.

## Решение

Скрипт читает файлы в порядке записи и разделяет их на эпохи перевода часов
назад. Это ключи порядка событий, а не измерение физически прошедшего времени.
Сопоставление предполагает, что каждый журнал содержит наблюдаемый перевод. Затем он:

1. восстанавливает прохождение туб через S1, толкатель и S2 по счётчикам ПЛК;
2. связывает решения камеры с кодами и коробами;
3. сопоставляет вердикты с зарегистрированными толчками;
4. сверяет `MarkEnd` со счётчиком нанесений `MarkCount` после обрывов связи;
5. сравнивает накопительный `n_out` с числом записанных кодов;
6. проверяет глобальную уникальность кодов во всех коробах.

Неоднозначные интервалы опроса не считаются ошибками без дополнительного
подтверждения. Это уменьшает число ложных срабатываний.

## Запуск

Требуется Python 3.12, сторонние библиотеки не нужны.

```bash
python3 найти.py /путь/к/смене
```

В указанной папке либо во вложенной папке `data` должны находиться:

- `station.log`;
- `plc.csv`;
- `laser.log`;
- `boxes.csv`.

Результат печатается в stdout как CSV с разделителем `;`:

```text
вид;время;туба;код;короб;причина
```

Например, результат можно сохранить в файл:

```bash
python3 найти.py ./смена > ответ.csv
```

## Ограничение

Ручное снятие тубы после S2 не видно в цифровых счётчиках и автоматически
не объявляется доказанным случаем. Нужен отдельный датчик стола или свидетельство
оператора для разбора конкретной смены.

Время S1 оценивается по опросам ПЛК, а не измеряется точно. Для дубля записей
коробов без истории камеры неизвестные время и номер тубы остаются пустыми.
Полная физическая реконструкция движения и дедлайнов при изменении скорости
и пропусках журналов пока не реализована.
